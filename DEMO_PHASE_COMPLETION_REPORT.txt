6. 3D IMPLEMENTATION DETAILS
================================================================================
- **Geometry Pipeline**: 2D Polygon coordinates `[[x1, y1], [x2, y2]...]` -> `THREE.Shape` -> `<extrudeGeometry>` with beveling.
- **Lighting & Environment**: Directional light with 2048x2048 shadow mapping, ambient light (intensity 0.75), hemisphere light, soft background fog (`#0f172a`), and `ContactShadows`.
- **Camera Rig**: Smooth cubic ease-out camera position and `OrbitControls` target lerping when a plot is searched or selected.
- **Floating Labels**: HTML overlays anchored to polygon centroids using `@react-three/drei` `<Html>` rendering plot numbers and status tooltips.

================================================================================
10. BOOKING WORKFLOW
================================================================================
1. User selects an AVAILABLE plot (e.g. P-102) and clicks `[ Book Now ]`.
2. Modal dialog opens pre-filled with plot number and price.
3. User enters Full Name and Phone Number, then clicks "Submit Booking Request".
4. The system updates plot P-102 status in React state from `AVAILABLE` to `BOOKED`.
5. Display confirmation screen with generated reference ID (e.g. `SKY-2026-84920`).
6. The 3D and 2D viewers immediately update P-102 to dimmed amber booked status. The plot can no longer be booked again during the session.
